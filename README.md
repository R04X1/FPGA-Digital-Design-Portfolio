
# FPGA Digital Design Portfolio

A collection of FPGA-oriented digital design projects developed using Verilog, VHDL, and Xilinx Vivado.

This projects focuses on digital logic design, RTL development, simulation, and hardware-oriented arithmetic.

## Projects

| Project | Description |
|---|---|
| [8-bit ALU](projects/8-bit-alu/) | Arithmetic Logic Unit design |
| [8-bit ALU - Alternative](projects/8-bit-alu-new/) | Alternative ALU implementation |
| [K2RED](projects/k2red/) | Modular reduction algorithm |
| [4-bit Counter](projects/4-bit-counter/) | Sequential logic and counting |
| [1-bit Full Adder](projects/1-bit-full-adder/) | Basic binary addition |
| [4-bit Full Adder](projects/4-bit-full-adder/) | Multi-bit binary addition |

## Tools and Technologies

- Verilog / VHDL
- Xilinx Vivado
- FPGA-oriented RTL design
- Digital logic simulation

## Verification

Projects include computer-based simulation and, where available, FPGA constraint files and hardware testing.
