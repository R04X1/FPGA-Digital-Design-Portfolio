
# 8-bit ALU - Alternative Version

An alternative 8-bit ALU implementation developed using Verilog and Xilinx Vivado.

## Technologies
- Verilog HDL
- Xilinx Vivado

## Project Overview
This project contains an alternative implementation of an 8-bit Arithmetic Logic Unit.

## Verification
- Computer-based testing
- Physical FPGA testing not performed

## Status
Design comparison and documentation in progress.
