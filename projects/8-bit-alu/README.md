
# 8-bit ALU

An 8-bit Arithmetic Logic Unit (ALU) design developed using Verilog and Xilinx Vivado.

## Technologies
- Verilog HDL
- Xilinx Vivado

## Project Overview
This project explores combinational digital logic and arithmetic operations through an 8-bit ALU implementation.

## Verification
- Computer-based testing
- Physical FPGA testing not performed

Documentation in progress.
