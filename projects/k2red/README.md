
# K2RED Modular Reduction

A Verilog-based study of the K2RED modular reduction algorithm for hardware-oriented arithmetic optimization.

## Technologies
- Verilog HDL
- Xilinx Vivado
- Python (reference model)

## Project Overview
This project investigates modular arithmetic and hardware implementation techniques relevant to cryptographic computations.

## Verification
- Software-based testing
- RTL simulation and synthesis results documented in the project report
- Physical FPGA testing not performed

## Status
Technical documentation and source code review in progress.
