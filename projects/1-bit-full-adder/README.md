
# 1-bit Full Adder

A basic digital logic project implementing a 1-bit full adder using HDL.

## Technologies
- HDL-based digital design
- Xilinx Vivado

## Project Overview
The project explores binary addition using two input bits and a carry-in signal to produce sum and carry-out outputs.

## Project Files
- rtl/: Design source files
- tb/: Simulation source files
- constraints/: FPGA constraint files
