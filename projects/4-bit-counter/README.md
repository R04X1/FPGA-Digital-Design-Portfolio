
# 4-bit Counter

A 4-bit digital counter designed using HDL and Xilinx Vivado.

## Project Overview
This project explores sequential digital logic and binary counting.

## Tools
- Xilinx Vivado
- HDL (Verilog/VHDL)

## Project Structure
- `rtl/` - Design source files
- `tb/` - Simulation and testbench files
- `constraints/` - FPGA constraint files

## Verification
Simulation and hardware verification details will be documented.

Documentation in progress.
