
# 4-bit Full Adder

A 4-bit binary adder project developed using HDL and Xilinx Vivado.

## Technologies
- HDL-based digital design
- Xilinx Vivado

## Project Overview
This project explores multi-bit binary addition and combinational digital logic design.

## Project Files
- rtl/: Design source files
- tb/: Simulation source files
- constraints/: FPGA constraint files

## Status
Documentation and verification details in progress.
